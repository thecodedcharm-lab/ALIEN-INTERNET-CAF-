# ALIEN-INTERNET-CAFE-
# 👽 COSMO CAFE | Alien Internet Café 🛸

> ☕ Coffee so powerful, you'll see 7 dimensions before breakfast.

Welcome to **Cosmo Cafe**, an imaginary intergalactic coffee shop serving cosmic drinks to aliens from across the universe! 🌌

This mini project is a creative frontend website built using HTML and CSS, featuring a futuristic cyberpunk theme, neon colors, and floating space elements.

## ✨ Features

* 🌌 **Cosmic UI:** Dark backgrounds with neon green and pink accents.
* 👽 **Alien Animation:** A floating alien character.
* 🛸 **Space Elements:** Animated UFO and rotating planet.
* ☕ **Cosmic Menu:** Three fictional drinks with prices.
* ✨ **Hover Effects:** Interactive buttons and animated menu cards.
* 📱 **Responsive Design:** Adapts to different screen sizes.
* 🎨 **Custom Typography:** Futuristic fonts using Google Fonts.
* 🧭 **Smooth Scrolling:** Navigate between sections seamlessly.

## 🛠️ Tech Stack

* **HTML5:** Website structure and content.
* **CSS3:** Styling, animations, layouts, and responsive design.
* **Google Fonts:** Orbitron and Poppins typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Navigate to the project folder

```bash
cd alien-cafe
```

### 3. Run the project

Open `index.html` in your web browser.

No additional installation is required!
